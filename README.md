# portfolio

Interactive personal portfolio for Gabriel Couto.

## Technology Stack

* HTML5
* CSS3
* Vanilla JavaScript (ES6+)
* Lucide Icons

## Fonts

The Inter typeface is self-hosted (`frontend/assets/fonts/`, declared in
`frontend/css/fonts.css`) under the SIL Open Font License. No external font
services are used, so the page renders with its intended typography from the
first paint without flash-of-unstyled-text or late font swaps.

## Development Setup

Requirements:

* Python 3 (recommended) or Node.js (nvm)

## How to Run the Frontend

From the project root:

```bash
./run.sh
```

Then open http://localhost:8000 in your browser.

To use a different port:

```bash
./run.sh 8080
```

Press `Ctrl+C` to stop the server.

See `AGENTS.md` for architecture and project rules.
