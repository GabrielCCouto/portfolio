# portfolio

Interactive personal portfolio for Gabriel Couto.

## Technology Stack

* HTML5
* CSS3
* Vanilla JavaScript (ES6+)
* Lucide Icons

## Development Setup

Requirements:

* Python 3 (recommended) or Node.js (nvm)

## How to Run the Frontend

From the project root:

```bash
./run.sh
```

Then open http://localhost:8000 in your browser.

To use a different port:

```bash
./run.sh 8080
```

Press `Ctrl+C` to stop the server.

See `AGENTS.md` for architecture and project rules.
